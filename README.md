# Pacman

A browser-based Pacman game built with plain HTML, CSS, and JavaScript.

## Run locally

Since this is a static web app, you can run it with any local web server.

### Option 1: Python (recommended)

1. Open a terminal in this project folder.
2. Start a local server:

```bash
python3 -m http.server 8000
```

3. Open your browser and go to:

```text
http://localhost:8000
```

### Option 2: VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension (if needed).
3. Right-click `index.html` and select **Open with Live Server**.

## Controls

- Arrow keys to move Pacman.
- Avoid ghosts and collect all pellets to win.
